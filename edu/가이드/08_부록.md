## 8.2 카메라 창 키 · 화면 읽기

| 키 | 하는 일 |
|---|---|
| `k` | 자세 방식 바꾸기 (① CAD 정합 ↔ ② 키포인트) |
| `i` | 검사 (화면 멈춤, 아무 키나 → 다시) |
| `c` | CAD 처음부터 다시 등록 |
| `r` | 책상 다시 찾기 |
| `v` | 3D 점군 보기 (Open3D) |
| `s` | 저장 (점군 + 리플레이용 장면) |
| `n` / `p` | (리플레이) 다음 / 이전 장면 |
| `q` | 종료 |

| 화면 | 뜻 |
|---|---|
| 박스 + 자세 이름 | 박스 모델이 찾은 브라켓 |
| 하늘색 윤곽 + 축 (빨강 X · 초록 Y · 파랑 Z) | 구한 6D 자세 (CAD 를 그 자세로 그림) |
| 노란 줄 `물체 x · y · z`, `Rx · Ry · Rz` | 맨 위 (집을) 브라켓의 자세. 펜던트에 가는 숫자 |
| `[CAD 정합] … 외 n개` / `[키포인트] 브라켓 n개 … ms/장` | 지금 방식과 브라켓 수 |
| 검사 윤곽: 초록 · 빨강 · 보라 · 주황 | 양품 · 불량 · 검사 안 함 (검은 브라켓) · 브라켓 아님 |

## 8.3 팔 API 요약

```python
from motion import Arm, load_pick_targets, load_all_pick_targets
arm = Arm()                 # 가상.  Arm(mode="real") 실기
```

| 명령 | 하는 일 |
|---|---|
| `arm.where()` | 관절 · 그리퍼 · 끝 위치 `xyz_mm` · 자세 `rpy_deg` |
| `arm.initial()` / `arm.home()` | 작업 시작 자세 / 관절 0 인 L 자 |
| `arm.moveL([x, y, z], "abs" 또는 "rel", rpy=…, speed=…, path=…)` | 그리퍼 끝을 직선으로 (mm). speed 5~45 mm/s (기본 25). `path="joint"` 면 관절 이동 |
| `arm.moveJ([j1 … j6], "abs" 또는 "rel", gripper=…, speed=…)` | 관절 6개 (도). speed 8~45 deg/s |
| `arm.grip(0~100)` | 0 닫힘, 100 완전히 열림 |
| `arm.stop()` | 진행 중인 이동 멈춤 (다른 실행 흐름에서) |
| `arm.close()` | 팔 끄기 |
| `load_pick_targets(arm)` | 카메라 창의 맨 위 브라켓 → `p_xyz` · `p_rpy` (대기), `g_xyz` · `g_rpy` (집기), `place_rpy` |
| `load_all_pick_targets(arm)` | 보이는 브라켓 모두, 가까운 순. 원소: `xyz` · `rpy` · `pose` · `color` · `verdict` · `pick` · `distance` |

약속: +X 앞 · +Y 왼쪽 · +Z 위, mm · 도. `"rel"` 은 더하기, `"abs"` 는 목표. `rpy` 는 늘 목표 자세.

## 8.4 오류 메시지 표

| 메시지 (마지막 줄) | 원인 | 해결 |
|---|---|---|
| `ArmError: mode는 'virtual' 또는 'real' 이어야 합니다` | `Arm(mode=…)` 오타 | `"virtual"` 또는 `"real"` |
| `ArmError: 실기 연결 실패 (…)` | 다른 프로그램이 팔을 잡음 · USB | 펜던트 끄기, 5.1 |
| `TypeError: moveL() missing 1 required positional argument: 'mode'` | `"rel"` / `"abs"` 빠뜨림 | 넣기 |
| `ArmError: moveL의 두 번째 인자는 'abs' 또는 'rel' 이어야 합니다` | 순서 바뀜, `"relative"`, 좌표를 리스트로 안 씀 | `arm.moveL([x, y, z], "rel")` |
| `ArmError: xyz는 mm 3개입니다` / `rpy는 deg 3개입니다` | 숫자 개수 | 세 개 |
| `ArmError: IK 실패 … / 목표까지 … mm 남음 / 이동 막힘` | 닿지 않는 자리 · 자세 (오류까지 1분쯤 걸리거나, 오류 없이 닿는 데까지만 가기도 한다) | 숫자 다시 보기, `where()` 로 확인 (7차시) |
| `ArmError: 이미 종료된 Arm 입니다` | `close()` 뒤 명령 | 1절부터 다시 |
| `ArmError: 카메라 창이 응답하지 않습니다. 실행중인지 확인해주세요` | 카메라 창 꺼짐 · 멈춤 | 카메라 창 켜기 |
| `ArmError: 바운딩 박스가 없습니다. 카메라 창을 확인해 주세요.` | 화면에 브라켓이 없음 | 브라켓 · 팔 위치 |
| `ArmError: 등록에 실패했습니다. 카메라 창을 확인해 주세요.` | CAD 정합 실패 | `c` 로 다시, 브라켓 위치 바꾸기, 또는 `k` 로 ② |
| `ArmError: 이미 등록 중입니다.` | 요청이 겹침 (버튼과 코드 동시) | 하나 끝나고 다시 |

## 8.5 용어집

| 용어 | 뜻 (수업에서 쓰는 말로) |
|---|---|
| 베이스 좌표 | 로봇 받침 한가운데가 0. +X 앞 · +Y 왼쪽 · +Z 위, mm |
| TCP | 그리퍼 끝 점 (Tool Center Point) |
| rpy (Rx · Ry · Rz) | 자세를 나타내는 세 각도 (roll · pitch · yaw), 도 |
| 6D 자세 | 위치 3개 + 방향 3개. 물체를 집으려면 필요 |
| 서보 | 각도를 읽고, 각도 명령을 받는 모터 |
| 리더 · 팔로워 | 손으로 움직이는 팔 · 그것을 따라 모터로 움직이는 팔 |
| 텔레오퍼레이션 | 리더로 팔로워를 원격 조종 |
| IK (역기구학) | "끝을 여기로" → 관절 각도를 계산하는 것. 실패하면 닿지 않는 자리 |
| 캘리브레이션 | 기준을 맞추는 일. 팔 캘리브 (관절 0°), 카메라 내부 값, 손눈 |
| 손눈 캘리브레이션 | 카메라가 로봇 기준 어디에 · 어느 방향으로 있는지 구하는 것 (카메라 ↔ 로봇 번역표) |
| 내부 파라미터 (intrinsic, K) | 카메라 · 렌즈 자체의 값 (fx · fy · cx · cy). 픽셀 + 깊이 → 카메라 기준 3D. 카메라를 옮겨도 그대로 |
| 외부 파라미터 (extrinsic, T_base_cam) | 카메라가 놓인 자리와 방향 (4×4: 오른쪽 열 = 위치, 왼쪽 3×3 = 방향). 손눈 캘리브의 결과. 카메라를 옮기면 다시 |
| 점군 | 깊이 카메라가 잰 3D 점들 |
| CAD | 물체의 설계도 모양 (여기서는 브라켓 STL) |
| ICP · CAD 정합 | 점군에 CAD 를 겹쳐 가장 잘 맞는 자세를 찾는 것 (① 방식) |
| 키포인트 | 물체에서 정해 둔 점 (브라켓은 10개) |
| PnP | 사진에 찍힌 점들의 위치로 물체 자세를 계산하는 것 (② 방식) |
| YOLO | 사진에서 물체를 찾는 딥러닝 모델 (박스 · 키포인트) |
| 라벨 | 학습용 정답 (박스와 자세 종류, 또는 점) |
| 미세조정 | 미리 학습한 기본 모델에 몇 장 더 가르치기 |
| 섞음 세트 | 기본 모델이 원래 공부한 사진 일부. 미세조정 때 섞어 원래 실력을 잊지 않게 한다 |
| 에폭 | 학습 사진 전체를 한 바퀴 보는 것 |
| mAP50 | 물체를 빠짐없이, 정확히 찾았는지 점수 (1 에 가까울수록 좋음) |
