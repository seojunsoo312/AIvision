# 3.1 1차시 — 시작과 로봇팔 구조 (60분)

## 목표

- 오늘 만들 결과를 보고 기대를 갖는다.
- 안전 수칙과 비상 정지를 안다.
- **리더 팔로 로봇 팔을 직접 움직여 본다** (첫 20분 안에).
- 관절 7개 · 서보 · 리더와 팔로워가 무엇인지 안다.

## 시간 배분

| 분 | 활동 | 화면 |
|---|---|---|
| 0–10 | 오리엔테이션: 목표, 완성 데모 | PPT 0장 · 1차시 표지, 데모 영상 |
| 10–20 | ⚠ 안전 수칙 · 비상 정지 · 장비 이름 | PPT 1차시 2~4 |
| 20–45 | **텔레오퍼레이션 체험** | 강사 시연 → 학생 실습 |
| 45–60 | 방금 어떻게 움직였나: 관절 7개 · 서보 · 리더와 팔로워 | PPT 1차시 7~9 |

## 0–10 오리엔테이션

**설명할 것**
- 오늘의 목표: 카메라로 브라켓을 찾아 집고, 마커 불량을 골라낸다
- 하루 흐름: 오전 팔 다루기 · 카메라 맞추기 → 오후 인식 · 보고 집기

시연: 완성 데모 영상 (보고 집기 · 불량 검사) **[실물 확인: 영상 촬영]**. 영상이 없으면 강사 보드에서 바로 `--grasp` 픽앤플레이스를 한 번 보여 준다 (강사 보드는 미리 4 · 5차시까지 해 두었을 때).

## 10–20 ⚠ 안전 수칙 · 비상 정지 · 장비 이름

**설명할 것** (안전, 6장)
- 팔이 움직이는 동안 작업 범위에 손 · 얼굴을 넣지 않는다
- 펜던트: **Space = 멈춤** (팔이 그 자리에서 버팀), **Esc = 비상 정지** (팔 힘이 빠져 떨어짐 → 받칠 수 있을 때만)
- 텔레오퍼레이션에서는 Space · Esc 가 안 된다. Ctrl + C 로 끄며, 이때도 힘이 빠진다 → 팔을 낮게 두거나 받친다

장비 이름: 보드 (Jetson), 팔로워 (모터로 움직이는 팔), 리더 (손으로 잡는 팔), 카메라, 그리퍼 (손).

자세한 안전 내용은 6장.

## 20–45 텔레오퍼레이션 체험

### 강사 시연 (5분)

1. 펜던트가 꺼져 있는지 확인한다 (펜던트와 같은 팔을 동시에 쓸 수 없다).
2. 리더를 팔로워와 **비슷한 자세**로 둔다. ⚠ 자세가 많이 다르면 시작하자마자 팔로워가 리더 자세로 확 움직인다.
3. 오른쪽 아래 칸에서:
   ```bash
   python deploy/teleoperate_7dof.py
   ```
4. 리더를 천천히 움직여 팔로워가 따라오는 것을 보여 준다. 그리퍼도 열고 닫는다.
5. 같이 뜬 그래프 창을 보여 준다: 관절마다 한 칸, **파란 선 = 리더, 주황 선 = 팔로워**. 두 선이 벌어지면 팔로워가 못 따라가는 것.
6. 팔로워를 손으로 받친 채 터미널에서 **Ctrl + C**.

### 학생 실습 (20분)

같은 순서로 한다. 미션:
1. 그리퍼로 블록을 책상 위에서 밀어 정해진 칸에 넣기
2. 블록을 집어 들어 옆으로 옮기기
3. (빠른 학생) 브라켓을 집어 세우기 → 눕히기

**설명할 것**
- 리더는 천천히. 빨리 휘두르면 팔로워가 못 따라온다
- 이 모드는 책상 · 자기 몸과의 충돌을 검사하지 않는다

### 잘 되면

- 리더를 움직이는 대로 팔로워가 거의 같이 움직인다.
- 그래프에서 파란 선과 주황 선이 거의 겹친다.

### 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 포트를 못 연다는 오류 | 펜던트 · 노트북이 팔을 잡고 있음 | 펜던트 창 닫기, 노트북 커널 종료 후 다시 |
| 시작하자마자 팔로워가 확 움직임 | 리더와 자세가 많이 다름 | Ctrl + C (팔 받치고) → 리더를 팔로워 자세에 맞춘 뒤 다시 |
| 한 관절만 반대로 · 이상하게 움직임 | 팔 캘리브 문제 | 그 자리는 강사 보드로 체험시키고, 쉬는 때 `bash deploy/calibrate_arms.sh` (5.1) |
| 그래프 창이 느려 끊김 | 그래프 그리기 부담 | `python deploy/teleoperate_7dof.py --display_data=false` |
| `/dev/so101_follower` 없음 | USB 빠짐, 이름 규칙 없음 | USB 다시 꽂기, `ls /dev/so101_*` (5.1) |

⚠ 끝낼 때 **Ctrl + C 를 누르면 팔로워 힘이 빠져 떨어진다.** 반드시 팔을 낮게 두거나 받친다.

## 45–60 방금 어떻게 움직였나

**설명할 것**
- 관절 7개 (6개 + 그리퍼), 관절마다 **서보 모터**: 지금 각도를 알려 주고, 각도 명령을 받는 모터
- 리더 서보는 힘을 빼고 각도만 읽는다 → 컴퓨터가 1초에 수십 번 읽어 팔로워 서보에 같은 각도를 보낸다

PPT 1차시 7~8: 관절 7개 이름과 위치, 리더 → 컴퓨터 → 팔로워 그림.

| 펜던트 표시 | 이름 | 하는 일 |
|---|---|---|
| J1 | shoulder_pan | 어깨 돌리기 (좌우) |
| J2 | shoulder_lift | 어깨 들기 |
| J3 | elbow_flex | 팔꿈치 굽히기 |
| J4 | elbow_roll | 팔꿈치 돌리기 (끝없이 도는 관절) |
| J5 | wrist_flex | 손목 들기 |
| J6 | wrist_roll | 손목 돌리기 |
| 그리퍼 (S7) | gripper | 손 열고 닫기 |

> 그런데 이렇게 사람이 매번 손으로 움직일 수는 없겠죠. 다음 시간부터는 "어디로 가라" 를 숫자로 알려 주는 법을 배웁니다. 그러려면 먼저 로봇이 쓰는 좌표를 알아야 합니다.

## ⏱ 시간 조절

- 모자라면: 텔레오퍼레이션 미션 3을 빼고, 관절 설명을 2차시 앞부분으로.
- 남으면: 짝끼리 한 사람은 리더, 한 사람은 "블록 위치" 를 말해 주며 협업 미션.
