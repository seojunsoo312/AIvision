# 7. 수업 후 정리와 초기화

## 7.1 정리 순서

1. 프로그램 끄기
   - 카메라 창 · 학습 창: `q`
   - 펜던트: 창 닫기 (실물이면 쉬는 자세로 간 뒤 닫힌다. 물체를 쥐고 있으면 확인 창이 뜬다)
   - 노트북: `arm.close()` → 커널 종료
   - 텔레오퍼레이션: 팔을 받치고 Ctrl + C
2. 팔을 쉬는 자세 (낮게) 로. 그리퍼에 아무것도 없게.
3. 보드 끄기: 화면 메뉴에서 종료 (전원을 그냥 뽑지 않는다).
4. 브라켓 · 블록 · ChArUco 보드 · 자 · 마커를 자리별 상자에.

## 7.2 다음 기수를 위한 초기화

```bash
cd ~/AIvision
python reset_class.py --all        # 목록을 보여 주고 yes 를 쳐야 지운다 (-y 면 묻지 않음)
```

| 옵션 | 지우는 것 |
|---|---|
| `--yolo` | 찍은 사진, 박스 라벨, 키포인트 라벨, 학습 결과 (`box_best.pt`, `kpt_best.pt`, `yolo/runs/`) |
| `--calib` | 카메라 캘리브 (내부 값, 손눈 사진과 결과) |
| `--ply` | 저장한 점군 |
| `--all` | 위 세 가지 모두 |

**남는 것**: 코드, CAD, 팔 캘리브, 필터 값, 박스 기본 모델 (`box_base.pt`) · 박스 섞음 세트, 키포인트 기본 모델 (`kpt_base.pt`) · 키포인트 섞음 세트.

초기화 뒤에는 `box_best.pt` 가 없어 물체 인식 창 (`roi_cloud.py`) 이 켜지지 않는다 (학생이 5차시에 학습하면 켜진다). 정상이다. 손눈 캘리브 · 카메라 확인은 그대로 켜진다.

학생이 고친 노트북을 지우려면 「AIvision 업데이트」 아이콘을 쓴다 (고친 것은 바탕화면 `AIvision_백업/` 에 남는다).

## 7.3 장비 점검과 보관

| 확인 | 할 일 |
|---|---|
| 그리퍼 손가락 · 케이블 | 헐거우면 조이고, 끊어질 듯하면 바꾼다 |
| 카메라 받침 | 흔들리면 고정 (다음 기수는 어차피 손눈을 새로 하지만, 수업 중에 움직이면 안 된다) |
| 마커 표시 브라켓 | 다음 기수에도 쓰면 표시가 지워지지 않았는지 |
| 수업 중 튄 팔 | 팔 캘리브 확인 (`bash deploy/calibrate_arms.sh`) |
