# 4. Python 을 처음 보는 학생 대응

이 수업에서 학생이 직접 쓰는 코드는 3 · 7 · 8차시의 노트북 (완성본 또는 빈칸본) 뿐이다 (8차시 미션은 원하면 `user_pickandplace.py` 로도). 문법을 가르치기보다 **"칸을 순서대로 실행하고, 숫자를 바꾸고, 오류의 마지막 줄을 읽는다"** 세 가지를 익히게 한다.

## 4.1 노트북 칸 실행

| 할 일 | 방법 |
|---|---|
| 칸 실행하고 다음 칸으로 | **Shift + Enter** |
| 지금 칸만 실행 | Ctrl + Enter |
| 실행 중인 칸 멈추기 | 위 메뉴 ■ (중단) |
| 처음부터 다시 | 커널 → 재시작 → 1절부터 |
| 실행 중인지 보기 | 칸 왼쪽 `[*]` (실행 중) → `[3]` (끝남, 숫자는 실행 순서) |

규칙 세 가지:
1. **위에서부터 한 번씩.** 아래 칸은 위 칸에서 만든 `arm` 을 쓴다.
2. **「1절 팔 켜기」 는 한 번만.** 두 번 하면 팔이 두 개 겹친다 → 커널 재시작.
3. 이동 칸은 팔이 **도착할 때까지** `[*]` 로 남는다. 끝나기 전에 다음 칸을 누르면 줄을 서서 기다린다.

## 4.2 오류 읽는 법

**설명할 것**
- 빨간 글씨가 길어도 **맨 마지막 줄** 만 본다. 앞부분 = 오류 종류, 뒷부분 = 이유

예:
```
ArmError: xyz는 mm 3개입니다
```
→ 좌표를 세 개 (x, y, z) 넣지 않았다.

| 오류 종류 | 뜻 | 흔한 원인 |
|---|---|---|
| `ArmError` | 팔 명령이 받아들여지지 않음 | 숫자 개수 · 범위, 닿지 않는 자리, 카메라 창 꺼짐 |
| `NameError` | 그런 이름이 없음 | 위 칸을 안 실행 (`arm`), 오타 |
| `TypeError` | 인자가 빠지거나 많음 | `"rel"` / `"abs"` 빠뜨림 |
| `SyntaxError` | 문법 오류 | 괄호 · 따옴표 짝, 콤마 |

자주 나오는 `ArmError` 문구와 원인은 부록 8.4.

## 4.3 자주 하는 실수

| 실수 | 예 | 바로잡기 |
|---|---|---|
| 따옴표 빠뜨림 | `arm.moveL([30, 0, 0], rel)` | `"rel"` |
| 대괄호 대신 괄호 · 빠뜨림 | `arm.moveL(30, 0, 0, "rel")` | `arm.moveL([30, 0, 0], "rel")` |
| 대소문자 | `arm.movel(...)`, `arm = arm()` | `moveL`, `Arm()` |
| 한글 · 전각 문자 | `arm.moveL([30，0，0], "rel")` (전각 콤마) | 영문 입력으로 다시 |
| 칸 건너뜀 | 3절부터 실행 | 1절부터 |
| mm 대신 m · cm | `[0.2, 0, 0.1]`, `[20, 0, 10]` | 모두 mm: `[200, 0, 100]` |
| rpy 를 "더하는 각도" 로 | `rpy=[0, 0, 10]` 로 10° 돌리기 | rpy 는 목표 자세. 지금 자세를 `where()` 로 읽고 더해서 넣기 |

## 4.4 진도 차이 관리

- **짝 짓기**: Python 을 해 본 학생과 처음인 학생을 짝으로. 실기는 한 사람이 키보드, 한 사람이 팔 옆에서 숫자 확인 (특히 Z).
- **막힌 학생**: 강사용 노트북 (강사 PC 바탕화면 `로봇 제어 실습_강사용.ipynb`) 의 그 칸만 보여 준다 (통째로 복사시키지 않는다).
- **빠른 학생용 추가 과제**
  - 3차시: 네 점을 차례로 들렀다 오기
  - 7차시: 블록 두 개 쌓기, 반복문으로 여러 번 옮기기
  - 8차시: 자세 종류마다 놓는 자리 다르게, 두 방식 성공률 비교
- 업데이트 아이콘을 누르면 노트북이 처음 상태로 돌아간다. 학생이 고친 것은 바탕화면 `AIvision_백업/` 에 남는다.
