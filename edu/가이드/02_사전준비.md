# 2. 사전 준비

수업 당일에 막히는 것은 대부분 준비 단계에서 막을 수 있다. 수업 시작 전과 수업 직후에 아래 순서대로 한다.

## 2.1 수업 시작 전

### 1) 초기화 (reset)

지난 기수가 만든 것을 지운다. 보드마다:

```bash
cd ~/AIvision
python reset_class.py --all        # 목록을 보여 주고 yes 를 쳐야 지운다
```

| 지우는 것                                          | 남는 것                                |
| ---------------------------------------------- | ----------------------------------- |
| 찍은 사진, 박스 라벨, 키포인트 라벨                          | 코드, CAD                             |
| 학습 결과 (`box_best.pt`, `kpt_best.pt`, `yolo/runs/`) | 기본 모델 두 개, 섞음 세트 두 개                |
| 카메라 캘리브 (내부 값 + 손눈)                            | 팔 캘리브 (리더 · 팔로워)                    |
| 저장한 점군                                         | 필터 값 (`vision/orbbec_filters.json`) |

> 초기화 뒤에는 `box_best.pt` 가 없어서 **학생이 5차시에 학습하기 전까지 물체 인식 창 (`roi_cloud.py`) 이 켜지지 않는다.** 손눈 캘리브 (`capture.py`) · 카메라 확인 (`vision_test.py`) 은 `box_best.pt` 없이 켜진다. 4차시의 집기 시연은 강사 보드에서 한다.

### 2) 업데이트

보드마다 바탕화면 **「AIvision 업데이트」** 아이콘을 더블클릭한다 (펜던트 · 카메라 창 · 노트북을 모두 끈 뒤).

- 마지막 줄 `✅ 업데이트 완료 — 버전 xxxxxxx · 통과 n · 경고 n · 실패 0` 에서 **8대의 버전 번호가 같은지** 본다.
- 업데이트하면 실습 노트북 (`로봇 제어 실습.ipynb`) 이 처음 상태로 돌아간다. 학생이 고친 것은 바탕화면 `AIvision_백업/날짜_시각/` 에 남는다.
- 강사 보드 (개발용) 에서는 아이콘을 쓰지 않는다.

### 3) 보드 점검

보드마다 한 바퀴 (1대 5분 소요). 체크표는 부록 8.7.

| #   | 확인           | 방법                                                      | 정상                                       |
| --- | ------------ | ------------------------------------------------------- | ---------------------------------------- |
| 1   | 터미널          | 「AIvision 터미널」 아이콘                                      | 4칸 모두 `(AIvision)`                       |
| 2   | 팔로워 · 리더 연결  | `ls /dev/so101_*`                                       | 두 줄                                      |
| 3   | 텔레오퍼레이션      | `python deploy/teleoperate_7dof.py`                     | 팔로워가 리더를 따라온다                            |
| 4   | 펜던트          | `python pendant/main.py` → Connect → HOME → 초기자세 → 창 닫기 | L 자 → 초기자세                               |
| 5   | 카메라          | `python vision/handeye/vision_test.py`                  | 컬러 · 깊이 화면                               |
| 6   | 초기화 됐나       | `ls yolo/weights/`                                      | `box_best.pt` 가 **없음**, `box_base.pt` 있음 |
| 7   | 키포인트 기본 모델   | `ls yolo/weights/kpt_base.pt`   | 있음                                       |

고장 · 불량 장비는 이때 바꾼다 (팔 케이블, 카메라 USB, 그리퍼 손가락).

### 그 밖에 준비할 것

**예비 자료** — 학생이 시간 안에 못 끝냈을 때 대신 쓸 것을 강사 보드에서 만들어 USB 에 둔다.

| 예비                        | 만드는 법                                                     | 쓰는 때                                       |
| ------------------------- | --------------------------------------------------------- | ------------------------------------------ |
| hand-eye calibration 파라미터 | 해당 수업에서 4차시를 미리 해 보고 **검증 1~3을 통과한** `vision/calib_data/` | 4차시에 못 끝낸 자리 (단, 카메라 받침이 그 자리와 같아야 의미가 있다) |
| 모델 가중치                    | 학생 책상 하나에서 5차시를 미리 해 본 `yolo/weights/box_best.pt`             | 5차시 학습이 실패한 자리                             |
| 장면                        | 카메라 창에서 `s` 로 저장한 `yolo/runs/roi/scenes/scene_*` 몇 개      | 카메라가 고장 난 자리 (`roi_cloud.py --replay 폴더`)  |

> 예비 손눈 캘리브는 **카메라 위치가 같을 때만** 맞다. 자리마다 카메라 받침이 조금씩 다르면 예비 파일로도 집기가 빗나간다. 그때는 검증 ②로 확인하고, 안 맞으면 점심 시간에 다시 찍는다.

**책상 배치**

- 책상 위를 비운다 (카메라 화면에 브라켓 말고 다른 물건이 없게).
- 브라켓: 학생마다 흰 2~3개, 검은 2~3개.
- 8차시 불량 검사용: 흰 브라켓 하나에 **마커로 선이나 점** (가로 5 mm 이상, 진하게). 구멍 바로 옆보다 판 가운데에.
- 8차시 미션용: 학생 책상마다 **작은 접시 2개**. 카메라 화면 오른쪽 위 (불량) · 오른쪽 아래 (양품) 에 두고, 펜던트로 두 접시 가운데의 X · Y 를 재서 노트북 9-3 의 `BAD_DISH` · `GOOD_DISH` 에 넣어 둔다. 접시는 테두리가 낮은 것 (놓는 높이가 집은 높이 + 30 mm). [실물 확인]
- ChArUco 보드, 블록, 자를 자리마다.

**강사 PC · 화면**

- 강사 보드 화면을 프로젝터로. 시연은 강사 보드에서 학생과 같은 명령으로 한다.
- 미리 열어 둘 것: PPT, `docs/diagrams/index.html`, `docs/실행 코드.md`, 바탕화면 `로봇 제어 실습_강사용.ipynb` (정답판, 학생 보드에는 없다).
- 강사 보드에는 수업 전에 4차시 (손눈 캘리브) 까지 해 둔다. 그래야 4차시에 카메라 창 · 집기 시연을 할 수 있다.

## 2.2 수업 직후

### 1) 보드 점검

수업 중에 문제가 생긴 장비를 다음 기수 전에 찾아 둔다. 보드마다:

- 2.1 의 보드 점검 3 · 4 · 5 (텔레오퍼레이션, 펜던트 HOME, 카메라 화면) 를 다시 해 본다.
- 그리퍼 손가락 · 케이블 · 카메라 받침이 헐겁거나 상했는지 본다.
- 수업 중 팔이 튀었던 자리는 팔 캘리브를 확인한다 (`bash deploy/calibrate_arms.sh`).

고장 난 것은 보드 번호와 함께 적어 두고 다음 수업 전에 바꾼다. 자세한 정리 순서와 장비 점검표는 7장.

### 2) 초기화 (reset)

2.1 의 초기화와 같다.

```bash
cd ~/AIvision
python reset_class.py --all
```

수업 직후에 지워 두면 다음 기수 학생의 사진 · 캘리브가 지난 기수 것과 섞이지 않는다. 다음 수업 시작 전에 한 번 더 해도 문제없다 (지울 것이 없으면 그대로 끝난다).
