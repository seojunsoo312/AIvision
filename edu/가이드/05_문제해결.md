# 5. 문제 해결 모음

증상 → 원인 → 해결 순서. 막히면 먼저 **그 자리의 다른 프로그램이 팔 · 카메라를 잡고 있지 않은지** 본다 (가장 흔한 원인). 실행 기록은 `~/aivision_logs/날짜.log`.

## 5.1 팔

| 증상 | 원인 | 해결 |
|---|---|---|
| 포트를 못 연다 · Connect 실패 · `ArmError: 실기 연결 실패` | 펜던트 · 노트북 · 텔레오퍼레이션 중 다른 것이 팔을 잡고 있음 | 다른 프로그램을 모두 끄고 다시 |
| `/dev/so101_follower` · `_leader` 가 없음 (`ls /dev/so101_*`) | USB 빠짐, 팔 이름 규칙 없음 | USB 다시. 그래도 없으면 `bash deploy/make_serial_rules.sh` (팔을 하나씩 꽂으며) |
| HOME 을 눌렀더니 팔이 튐 · 이상한 자세 | 팔 캘리브 문제 | 즉시 Esc (받친 채). `bash deploy/calibrate_arms.sh follower` 로 다시 (`docs/실행 코드.md` 1절) |
| 한 관절만 반대로 · 이상하게 (텔레오퍼레이션) | 리더 또는 팔로워 캘리브 | `bash deploy/calibrate_arms.sh leader` 또는 `follower` |
| 「IK 실패」 · 「go-to blocked」 · 「목표까지 … mm 남음」 | 팔이 닿지 않는 위치 · 자세, 충돌 | 덜 멀리 · 덜 낮게, 자세를 덜 기울여. 초기자세에서 다시 |
| 팔이 처져 있음 | Esc · Ctrl + C 로 힘이 꺼짐 | 펜던트 Connect 다시 (힘이 들어온다) |
| 「물체를 쥔 채 멈춤 — 손으로 받친 뒤 내려 주세요」 | 쥔 채로 막힘 · Stop | 물체를 받치고 Gripper Open |
| compute.py 뒤 HOME 이 L 자가 아님 | 팔 캘리브 L 자 틀어짐 | compute.py 의 「고칠까요?」 에 `y` (4차시) |

## 5.2 카메라

| 증상 | 원인 | 해결 |
|---|---|---|
| 화면이 안 나옴 · 「SDK 없음」 | Orbbec SDK 경로 · USB | `lsusb \| grep 2bc5` 가 두 줄인지, `docs/vision.md` 실행 절 |
| 「카메라를 열 수 없음」 류 | 카메라를 쓰는 프로그램이 이미 켜짐 (Viewer, 다른 창) | 카메라 프로그램은 한 번에 하나만 |
| 권한 오류 | udev 규칙 (`99-obsensor-libusb.rules`) 없음 | SDK 의 `script/install_udev_rules.sh`, 다시 꽂기 |
| 「카메라 창이 응답하지 않습니다」 (펜던트 · `load_pick_targets`) | 카메라 창이 꺼짐, 또는 30초 안에 못 끝냄 | 카메라 창 켜기. 켜져 있으면 창이 멈췄는지 (`i` 검사 화면에서 키를 안 눌렀는지) |
| 카메라 창 첫 줄이 `device=cpu` | GPU 용 torch 문제 | `docs/jetson_setup.md` 5번 확인 (강사) |
| 깊이 화면에 구멍이 많음 · 노출이 이상 | 필터 · 노출 값 | 카메라 창 옆 필터 창. 값은 `vision/orbbec_filters.json` 에 보드마다 저장 |
| 카메라가 고장 남 | | 예비 장면으로 `python yolo/pose/roi_cloud.py --replay 폴더` (`n` / `p` 넘기기). 화면 설명은 그대로 할 수 있다 |

## 5.3 손눈 캘리브

| 증상 | 원인 | 해결 |
|---|---|---|
| 보드 코너가 초록이 안 됨 (16개 미만) | 너무 기울임 · 화면 끝 · 반사 | 덜 기울이기, 화면 안쪽, 반사 피하기 |
| capture.py 가 저장을 안 함 | 펜던트 Connect · 토크 OFF · 팔이 움직이는 중 | Connect, 멈춘 뒤 SPACE |
| compute.py: 「유효 샘플 n장 — 20장 정도를 다시 찍으세요 (최소 12)」 | 코너를 찾은 사진이 12장 미만 | 20장 찍기 |
| compute.py: 「이상치 제거 후 n장. 보드 고정과 토크 ON 정지를 확인…」 | 보드가 흔들림 · 팔이 움직이는 중에 찍음 | 보드를 단단히, 멈춘 뒤 찍기, 처음부터 |
| 검증 ①: residual 이 큼, 한 장 빼고 변화가 큼 | 자세가 단조로움 | 손목 30° 이상 · 화면 구석까지 5~10장 더 → 다시 계산 |
| 검증 ①: 많이 제거됨 | 보드가 흔들림 | 보드를 단단히 붙이고 처음부터 |
| 검증 ②: 한쪽 코너만 높음 | 방향이 조금 틀어짐 | 더 다양하게 찍어 다시 |
| 검증 ③: 한 방향으로 일정하게 어긋남 | 카메라 받침이 움직임 | 받침 고정 확인, 움직였으면 처음부터 |
| 「펜던트를 끄고 다시 실행하세요」 | compute 가 팔 캘리브를 고치려는데 펜던트가 켜짐 | 펜던트 닫고 compute 다시 |
| 「팔 캘리브는 고치지 않음」 | 사진으로는 판단이 불확실 | 그 이유대로 사진을 다시 |
| 늦은 자리 | | 예비 캘리브 (검증 통과본, **카메라 받침이 같은 자리일 때만**) 를 `vision/calib_data/` 에 |

## 5.4 학습 · 라벨

| 증상 | 원인 | 해결 |
|---|---|---|
| 카메라 창이 「가중치 없음」 으로 안 켜짐 | 초기화 뒤 아직 학습 전 (정상) | 5차시 학습 뒤 켜진다. 급하면 예비 박스 가중치를 `yolo/weights/box_best.pt` 로 |
| `prepare.py`: 「라벨 쌍이 n개뿐입니다」 | 라벨 10장 미만 | 더 라벨 (20장 권장) |
| `train.py`: 「박스 기본 모델이 없습니다 … 처음부터」 | `box_base.pt` 복사 안 됨 | 기본 모델 복사 (`docs/jetson_setup.md` 빠른 설치). 처음부터 학습하면 20장으로는 거의 못 찾는다 |
| 「박스 섞음 세트가 없습니다 … 가볍게 학습」 | `box_base/` 복사 안 됨 | 진행은 되지만 새 책상 적응이 약함. 다음 기수 전에 복사 |
| `kpt_train.py`: 「시작 모델이 없습니다」 | 키포인트 기본 모델 복사 안 됨 | 기본 모델 복사 (`docs/jetson_setup.md` 빠른 설치) |
| `kpt_train.py`: 「기본 섞음 세트가 없습니다」 경고 | `kpt_base/` 복사 안 됨 | 진행은 되지만 원래 실력을 잊을 수 있다. 복사 |
| `kpt_train.py`: 「라벨한 사진이 n장입니다」 | 키포인트 라벨 4장 미만, 또는 저장 안 함 | `s` · `n` 으로 저장했는지 |
| 키포인트 라벨 도구가 「… 박스 라벨이 있습니다」 로 멈춤 | `--labels` 로 박스 라벨 폴더 지정 | 옵션 없이 `python yolo/train/kpt_label.py` (라벨은 `raw/kpt_labels` 에 따로) |
| `m` 을 눌러도 「자동 찍기 모델이 없습니다」 | 키포인트 기본 모델 없음 | 기본 모델 복사 (`docs/jetson_setup.md` 빠른 설치) |
| 메모리 부족으로 학습이 멈춤 | 다른 창이 켜져 있음 | 카메라 창 · 브라우저 · 노트북 끄고. 그래도면 `--batch 2` |
| 「System throttled due to Over-current」 | 보드 보호 동작 | 그대로 둔다 (학습은 끝난다) |
| `detect.py` 에서 자세를 자주 틀림 | 사진이 한 자세에 몰림 · 라벨 실수 | 부족한 자세를 더 찍어 라벨 → 다시 학습 |

## 5.5 자세 · 검사

| 증상 | 원인 | 해결 |
|---|---|---|
| 한 브라켓만 윤곽 · 자세가 엉뚱함 | 붙어 있음 (3 cm 미만) · 쌓임 · 기댐 · 화면 가장자리 | 떨어뜨려, 책상에 바로, 화면 안쪽으로 |
| 모든 브라켓 윤곽이 같은 쪽으로 어긋남 | 손눈 캘리브 | 4차시 기록표, 검증 ② 다시 |
| ① CAD 정합이 「CAD miss」 반복 | 깊이가 비어 있음 (반사 · 검은 물체 · 가장자리) | `c` 로 다시, 위치 바꾸기, `r` 책상 다시 찾기 |
| ① 맨 위 말고 나머지 브라켓이 늦게 · 가끔 안 나옴 | 나머지는 따로 차례로 맞추고, 깊이 잡음에 약함 | 정상 범위. 잠시 기다리기, 또는 `k` 로 ② |
| `k`: 「키포인트 방식을 쓸 수 없습니다」 | 6차시 키포인트 학습 전 (`kpt_best.pt` 없음) · 손눈 캘리브 없음 | 메시지가 이유를 알려 준다. `kpt_train.py` 학습, 4차시 |
| 카메라 창: 「박스 모델이 없습니다」 | 5차시 박스 학습 전 (`box_best.pt` 없음) | 정상. 5차시 `train.py` 뒤에 켜진다 |
| 검사: 마커가 있는데 양품 | 마커가 작음 · 연함 · 구멍 바로 옆 | 진하게, 5 mm 이상, 판 가운데 |
| 검사: 양품인데 불량 | 그림자 · 케이블 · 윤곽 어긋남 | 케이블에서 떨어뜨림, 윤곽이 테두리와 맞는지 |
| 검사: 보라 (검사 안 함) | 검은 브라켓 (정상) | |
| 검사: 주황 (브라켓 아님) | 브라켓이 아닌 것을 찾음 · 윤곽이 안 맞음 | 책상 위 다른 물건 치우기 |

## 5.6 화면 · 환경

| 증상 | 원인 | 해결 |
|---|---|---|
| 3D 화면 (meshcat) 이 하얗기만 함 | 예전 탭 · 연결 | 새로고침. 펜던트 · 노트북을 다시 켜기 |
| 창이 안 뜸 · `cv2.imshow` 오류 | 환경 설치 문제 | `docs/jetson_setup.md` (강사) |
| 한글이 □ 로 나옴 | 글꼴 (`fonts-noto-cjk`) | 강사 |
| `ModuleNotFoundError` · 이상한 Python 오류 | `AIvision` 환경이 아님, ROS 경로가 섞임 | `conda activate AIvision`, `unset PYTHONPATH` 뒤 다시. 「AIvision 터미널」 아이콘으로 열면 자동 |
| 펜던트 창 아래가 잘림 | 모니터 높이 | `python pendant/main.py --scale 0.8` |
| 업데이트 아이콘이 「펜던트 · 카메라 창 · 노트북이 켜져 있음」 | 프로그램이 켜짐 | 모두 닫고 다시 |
