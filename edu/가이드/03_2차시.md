# 3.2 2차시 — 좌표와 자세 (60분)

## 목표

- 로봇 베이스 좌표 (+X 앞, +Y 왼쪽, +Z 위, mm) 를 안다.
- TCP (그리퍼 끝) 의 위치 xyz 와 자세 rpy (도) 를 읽는다.
- 펜던트로 축마다 움직이고, 3D 화면 (meshcat) 과 실물이 같이 움직이는 것을 본다.

## 시간 배분

| 분 | 활동 | 화면 |
|---|---|---|
| 0–25 | 베이스 좌표 · TCP · xyz · rpy · 단위 | PPT 2차시 2~4 |
| 25–50 | 펜던트로 축마다 움직이기, 미션 | 펜던트 |
| 50–60 | meshcat 3D 화면과 실물 비교, 정리 | 브라우저 |

## 0–25 좌표 이야기

**설명할 것**
- 숫자로 움직이려면 "어디" 를 숫자로 말하는 약속이 필요하다
- 베이스 한가운데가 0, **+X 앞 · +Y 왼쪽 · +Z 위**, 단위 **mm**
- 움직이는 점은 그리퍼 끝 = **TCP**. 예: TCP (200, 0, 120) = 앞 20 cm, 높이 12 cm
- 같은 위치에서도 손 방향이 다를 수 있다 → **자세** = Rx · Ry · Rz (roll · pitch · yaw, 도)

PPT:
- 2장: 책상 사진 위에 X · Y · Z 화살표 (로봇 베이스에서)
- 3장: TCP 위치, Rx · Ry · Rz 가 각각 어느 축으로 도는지
- 4장: 같은 위치, 다른 자세 (손이 아래 · 옆 · 비스듬히)

확인 질문:
- "TCP 를 위로 5 cm 올리려면 어느 숫자를 얼마나 바꾸나요?" (Z 에 +50)
- "왼쪽으로 3 cm?" (Y 에 +30)

## 25–50 펜던트로 움직이기

### 강사 시연

1. 왼쪽 위 칸:
   ```bash
   python main.py
   ```
   (오른쪽 아래 칸이면 `python pendant/main.py`.) 펜던트 창이 왼쪽에, 3D 화면 (Chrome) 이 오른쪽에 뜬다.
2. 처음에는 **가상 팔** 이다 (3D 화면만 움직임). **Connect** 를 누르면 실물 팔이 연결된다.
3. **HOME** (관절이 모두 0 인 L 자) → **초기자세** (작업을 시작하는 자세).
4. 가운데 칸 **TCP** 의 X · Y · Z · Rx · Ry · Rz 줄: `−` / `+` 를 누르고 있는 동안 그 축으로 움직인다. 위쪽 상태 글자의 TCP 숫자가 바뀌는 것을 보여 준다.
5. 목표 입력칸에 숫자를 넣고 **TCP 이동** → 그 위치로 간다.
6. 왼쪽 칸 **Joints** 의 J1~J6 · 그리퍼: 관절 하나씩 움직이기.
7. ⚠ **Space** (Stop) 와 **Esc** (E-stop) 를 한 번씩 보여 준다. Esc 는 팔을 손으로 받친 상태에서.

### 학생 실습 (미션)

1. Z 만 움직여 그리퍼 끝을 책상 위 5 cm 에 맞추기 (상태 글자의 Z 를 보며)
2. X · Y 를 움직여 책상의 정해진 점 (테이프 표시) 바로 위에 그리퍼 끝 맞추기 → 그때의 X · Y 를 종이에 적기
3. 목표 입력칸에 2번에서 적은 X · Y 와 Z = 50 을 넣고 **TCP 이동** → 같은 곳에 오는지
4. Rz 만 바꿔 손목을 돌려 보기

**설명할 것**
- 미션 3이 핵심: 손으로 맞춘 자리를 숫자로 적어 두면 다음에는 숫자만으로 간다 (3차시에 코드로)

### 잘 되면

- `+X` 를 누르면 팔이 앞으로, `+Z` 를 누르면 위로 간다 (좌표 약속대로).
- 3D 화면의 팔과 실물이 같이 움직인다.

### 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| Connect 가 실패 | 텔레오퍼레이션 · 노트북이 팔을 잡고 있음, USB | 다른 프로그램 끄기, `ls /dev/so101_*` (5.1) |
| 3D 화면이 하얗기만 함 | 브라우저 연결 | 새로고침. 안 되면 펜던트 다시 (5.6) |
| 버튼을 눌러도 안 움직이고 상태에 「IK 실패」 · 「go-to blocked」 | 팔이 닿지 않는 위치 · 자세 | 조금 덜 멀리, 덜 낮게. 초기자세로 돌아가 다시 (5.1) |
| HOME 을 눌렀더니 팔이 튐 | 팔 캘리브 문제 | 즉시 Esc (받친 채), 강사 호출 (5.1) |
| 창 아래가 잘림 | 모니터 높이 | `python main.py --scale 0.8` |

## 50–60 3D 화면과 정리

**설명할 것**
- 3D 화면의 팔은 실물과 같은 숫자로 움직이는 디지털 트윈. 실물 없이 먼저 시험할 수 있다 (3차시는 가상 팔부터)

정리 (PPT 2차시 8):
- +X 앞 · +Y 왼쪽 · +Z 위, mm
- TCP = 그리퍼 끝, 위치 xyz + 자세 Rx · Ry · Rz (도)
- 펜던트: `−` / `+` 조그, 목표 입력 → TCP 이동, Space 멈춤 · Esc 비상 정지

마칠 때 펜던트 창을 닫는다 (실물이면 쉬는 자세로 간 뒤 닫힌다). 3차시 노트북이 팔을 쓰려면 펜던트가 꺼져 있어야 한다.

## ⏱ 시간 조절

- 모자라면: 미션 4 빼기, meshcat 설명을 3차시 첫머리로.
- 남으면: 짝이 불러 주는 좌표로 TCP 이동해 보기 (닿지 않는 좌표를 일부러 넣어 「IK 실패」 보기 → 7차시 오류 읽기 예고).
