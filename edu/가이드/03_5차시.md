# 3.5 5차시 — 물체 인식 (YOLO) + ① 박스 라벨 (60분)

## 목표

- 딥러닝 물체 인식이 "정답을 보여 주며 가르치는 것" 임을 안다.
- **미리 학습한 모델에 몇 장 더 가르치는 법 (미세조정, 반복 + 섞음 세트)** 을 안다.
- 사진 20장을 찍고, 박스와 자세 종류를 **직접** 라벨하고, 학습을 시작한다.

## 시간 배분

| 분 | 활동 | 명령 |
|---|---|---|
| 0–10 | 딥러닝 인식, 미세조정, 반복 + 섞음 세트 | PPT 5차시 2~4 |
| 10–25 | 사진 20장 찍기 | `yolo/train/capture.py` |
| 25–45 | 박스 + 자세 종류 라벨 (직접) | `label.py` |
| 45–50 | 학습 시작 | `prepare.py` → `train.py` |
| 50–60 | 학습 동안: 키포인트 개념 미리 | PPT 6차시 2~5 |

## 0–10 딥러닝 인식 이야기

**설명할 것**
- 사진과 정답을 보여 주며 가르친다. 정답 = **라벨** ("이 네모 안에 브라켓, 세워져 있음")
- 이 모델의 답: 브라켓마다 박스 + 자세 세 가지 (**세우기 · 눕히기 · 비스듬히**)
- 처음부터면 사진 수백 장 → **미리 공부한 기본 모델** 에서 시작해 책상 사진 20장만 더 = **미세조정**

**설명할 것** (PPT 5차시 4, 반복 + 섞음 세트)
- 20장만 계속 보여 주면 그 20장에 맞추느라 원래 잘 하던 것을 **잊어버린다**
- 그래서 내 사진은 **10번씩** (충분히 배우게), 기본 모델이 공부한 사진도 **섞어서** (잊지 않게)

근거 숫자 (노트북 시험, 학습에 안 쓴 사진으로 채점, `docs/yolo.md`):

| 학습 방법 | 학습에 안 쓴 실사진 점수 |
|---|---|
| 기본 모델 + 10번 반복 + 섞음 (우리 방법) | 0.995 |
| 기본 모델 + 10번 반복, 섞음 없이 | 0.884 (잊어버림) |
| 기본 모델 없이 처음부터 | 0.47 (절반도 못 찾음) |

(점수는 mAP50: 1 에 가까울수록 브라켓을 빠짐없이, 정확히 찾는다.)

## 10–25 사진 20장 찍기

왼쪽 아래 칸 (yolo):
```bash
python train/capture.py
```
`SPACE` 저장, `q` 끝. 사진은 `yolo/datasets/raw/images/` 에 쌓인다.

**설명할 것**
- 많이보다 **골고루**: 세 자세를 비슷한 수로, 흰 · 검 섞기, 여러 자리 · 방향
- 한 장에 2~3개를 **3 cm 이상 떨어뜨려** 놓아도 된다. 빈 책상도 한두 장
- 팔은 초기자세로 치워 두고 (조금 보여도 괜찮다)

## 25–45 박스 + 자세 종류 라벨 (직접)

```bash
python train/label.py
```

| 키 · 마우스 | 하는 일 |
|---|---|
| `0` / `1` / `2` | 자세 고르기: 세우기 / 눕히기 / 비스듬히 |
| 클릭 두 번 | 브라켓을 감싸는 네모의 대각선 두 점 |
| `d` 또는 우클릭 | 방금 그린 것 취소 |
| `n` | 다음 사진 (물체 없는 사진도 `n`) |

**설명할 것**
- 이번 라벨은 자동 없이 **직접**: 라벨이 무엇인지 손으로 익히는 단계
- 네모는 브라켓에 **딱 맞게**. 자세를 틀리게 고르면 모델도 틀리게 배운다

헷갈리는 자세 (PPT 그림으로):
- 세우기: L 자의 한 판이 책상에 닿고 다른 판이 위로 섬
- 눕히기: L 자가 옆으로 누워 두 판의 모서리가 책상에 닿음
- 비스듬히: 두 판의 끝이 책상에 닿아 ㅅ 자로 기댐

## 45–50 학습 시작

⚠ 학습은 메모리를 많이 쓴다. **카메라 창 · 브라우저 · 노트북을 끄고** 실행한다.

```bash
python train/prepare.py      # 학습용 / 검증용 나누기
python train/train.py        # 기본 모델 + 10번 반복 + 섞음 세트, 15 에폭
```

시작하면 터미널 첫 부분에 이런 줄이 보인다:
```
학생 사진 16장 (×10) + 섞음 300장 → 학습 460 · 검증 34
classes=['세우기', '눕히기', '비스듬히']  device=0  batch=4  epochs=15  model=.../box_base.pt
```
`device=0` 이면 GPU 로 학습 중이다 (`cpu` 면 5.4).

시간: 노트북 RTX 약 5분. **젯슨은 [실물 확인]** (예전 실측으로 어림하면 약 6분 이상). 끝나면 `복사 ... → yolo/weights/box_best.pt`.

학습 중 화면 위에 「System throttled due to Over-current」 가 뜰 수 있다. 보드 보호 동작이라 학습은 그대로 끝난다.

## 50–60 학습 동안: 키포인트 개념 미리

학습이 도는 동안 6차시 PPT 2~5 (6D 자세, 두 방식) 를 먼저 설명한다. 학습이 끝나면:

```bash
python train/detect.py
```
브라켓에 박스와 자세 이름이 뜨는지 본다 (`q` 끝).

### 잘 되면

- `detect.py` 에서 책상 위 브라켓마다 박스가 뜨고, 자세 이름이 맞다.
- 빈 책상에는 박스가 없다.

### 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| `prepare.py`: 「라벨 쌍이 n개뿐입니다」 | 라벨한 사진이 10장 미만 | 더 라벨 (20장 권장) |
| `train.py`: 「박스 기본 모델이 없습니다」 | `box_base.pt` 복사 안 됨 | 기본 모델 복사 (`docs/jetson_setup.md` 빠른 설치) (5.4) |
| 「박스 섞음 세트가 없습니다 … 가볍게 학습합니다」 | `box_base/` 복사 안 됨 | 그대로 진행해도 되지만 새 책상 적응이 약함. 다음 기수 전에 복사 |
| 메모리 부족으로 멈춤 | 다른 창이 켜져 있음 | 다 끄고 다시. 그래도면 `python train/train.py --batch 2` |
| `detect.py` 에서 자세를 자주 틀림 | 자세가 한쪽에 몰린 사진 · 라벨 실수 | 부족한 자세 사진을 더 찍어 라벨 → 다시 학습 |

## ⏱ 시간 조절

- 모자라면: 사진을 15장으로 (세 자세 각 5장). 라벨이 늦은 학생은 짝과 나눠서.
- 학습이 실패한 자리: 예비 박스 가중치를 `yolo/weights/box_best.pt` 로.
- 학습이 오래 걸리면: 6차시 앞부분 (키포인트 라벨) 을 먼저 시작해도 된다 (사진은 이미 있다).
