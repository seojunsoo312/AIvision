# 수업 PPT (목차 초안, 2026-11-09)

> 장 제목만 있는 초안이다. 확인받은 뒤 장마다 내용을 쓴다. 발표자 노트에는 강사 가이드 3장의 「설명할 것」 요점을 넣는다.
> 장 구성: 차시마다 표지 → 개념 (그림 위주, 글 짧게) → 실습 (명령과 화면) → 정리 1장. ★ 는 줄일 때 먼저 뺄 장.
> [그림] = `docs/diagrams/` 캡처, [화면] = 실물 화면 캡처 (실물 접근 때 채움, 그 전에는 자리만).

3. 오늘의 장비와 프로그램 [그림 시스템]

## 4차시 카메라와 손눈 캘리브 + 검증 (15장)

1. 표지
2. 카메라가 보는 것: 컬러 · 깊이 [화면]
3. **왜 캘리브레이션을 하나요?** 카메라는 "사진의 (320, 240) 픽셀", 로봇은 "베이스에서 앞으로 200 mm" — 말이 다르다 (그림: 같은 브라켓, 두 좌표)
4. 캘리브레이션 = 번역표. 틀리면? 1° 틀어짐 → 약 8 mm 빗나감 → 집기 실패 (그림 · ★시연 영상)
5. 렌즈 내부 값 (내부 캘리브)
6. **내부 파라미터 읽기 (K)**: fx · fy · cx · cy, 픽셀 하나 = 거리 ÷ fx mm
7. 손눈 캘리브: 카메라 좌표 → 로봇 좌표 (그림)
8. 실습: 보드 사진 찍기 — 팔 자세를 여러 가지로, 보드가 화면 곳곳에 [화면]
9. 실습: 계산하기 (`compute.py`) + 팔 캘리브 자동 점검 (「고칠까요?」 → `y`) [화면]
10. **외부 파라미터 읽기 (T_base_cam)**: 오른쪽 열 = 카메라 위치, 왼쪽 3×3 = 방향 (세로로 읽기)
11. 검증 ① 계산 숫자 읽기: 통과 기준 표
12. 검증 ② 책상 위 보드 높이 (`compare_pnp_depth.py`) [화면]
13. 검증 ③ 팔 끝으로 코너 찍어 보기 ⚠ 책상 위 20 mm 이상
14. 통과 못 하면: 다시 찍는 법 · 기록표 적기
15. 정리

## 5차시 물체 인식 (YOLO) + ① 박스 라벨 (10장)

1. 표지
2. 딥러닝 물체 인식이란 (박스 · 자세 종류)
3. 미리 학습한 모델에 몇 장 더 가르치기 (미세조정): 왜 20장이면 되나
4. 반복 + 섞음 세트: 내 사진은 10번씩 보여 주고, 원래 공부한 사진도 섞는다 → 새것을 배우면서 옛것을 잊지 않는다 (그림: 섞음 없이 반복하면 잊는 비교 표)
5. 사진 잘 찍는 법: 세 자세 · 흰 · 검 골고루, 여러 자리 · 방향
6. 실습: 사진 20장 찍기 [화면]
7. 라벨이란: 정답을 알려 주는 것
8. 실습: 박스 + 자세 종류 직접 그리기 (`label.py`) [화면]
9. 실습: 학습 시작 (`prepare.py` → `train.py`), 학습 그래프 읽는 법 [화면]
10. 정리 · 다음 차시 예고: 6D 자세

## 6차시 6D 자세 추정, 두 가지 방식 (11장)

1. 표지
2. 6D 자세란: 위치 x · y · z + 방향 Rx · Ry · Rz
3. **두 가지 방식 한눈에** [그림 6D 두 방식]
4. ① CAD 정합: 깊이 점군 → 책상 빼기 → 물체 모양 겹쳐 보기 (그림)
5. ② 키포인트: 점 10개 → 책상 붙이기 (그림)
6. 키포인트 라벨: 처음 2~3장은 직접, 그다음 `m` 으로 자동 [화면]
7. 실습: 키포인트 라벨 · 학습 시작 (`kpt_train.py`) [화면]
8. 실습: ① 결과 보기 — 점군 `v`, CAD 겹침 [화면]
9. 실습: `k` 로 두 방식 바꿔 보기, 숫자 비교 (기록표) [화면]
10. 두 방식 비교: 강점 · 약점, 시뮬 결과 표, 놓는 조건 (책상 위 · 3 cm · 쌓으면 안 됨)
11. 정리
