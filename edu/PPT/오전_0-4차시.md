### 4-6 내부 파라미터 읽기 (K)
```
[ fx   0   cx ]     [ 453.5    0     323.9 ]
[  0  fy   cy ]  =  [   0    453.5   243.5 ]
[  0   0    1 ]     [   0      0       1   ]
```
- `cx, cy` = 렌즈 정중앙 픽셀 (사진 한가운데 320, 240 근처)
- `fx, fy` = 확대 정도 → 거리 Z 에서 **픽셀 하나 = Z ÷ fx mm** (350 mm → 0.77 mm)
- 수식: **X = (u − cx) × Z ÷ fx** · **Y = (v − cy) × Z ÷ fy** · **Z = 깊이** (PPT 에서는 수식 개체로)
- 카메라 · 렌즈 자체의 값: 카메라를 옮겨도 그대로
- 예: 중심에서 오른쪽 100픽셀, 깊이 350 mm → 100 × 0.77 ≈ **오른쪽 77 mm**, 앞 350 mm
- 노트: 중심에서 몇 픽셀 × 픽셀 하나 크기 (거리 ÷ fx) = 중심에서 몇 mm. 아직 **카메라 기준** 이라 로봇은 못 알아듣는다.

### 4-10 외부 파라미터 읽기 (T_base_cam)
```
  카메라 x   카메라 y   카메라 z  │ 위치
[  0.036    -0.996    -0.076   │ 167.5 ]  ← 로봇 X (앞)
[ -0.999    -0.036    -0.001   │ -10.8 ]  ← 로봇 Y (왼쪽)
[ -0.002     0.076    -0.997   │ 347.6 ]  ← 로봇 Z (위)
[  0         0         0       │   1   ]  ← 무시
```
- **오른쪽 열 = 카메라 위치** (mm): 앞 168 · 오른쪽 11 · 높이 348
- **왼쪽 3×3 = 방향, 세로로 읽기**: 1열 사진 오른쪽 → 로봇 오른쪽 · 2열 사진 아래 → 로봇 뒤 · 3열 보는 방향 → 아래
- 카메라를 놓은 자리의 값: 옮기면 다시
- 활동: 자로 카메라 위치를 재서 오른쪽 열과 비교
- 노트: ±1 근처 칸만 보면 된다. 3열 −0.997 = 아래에서 약 4° 기울어짐. 계산 예는 가이드 4차시.
