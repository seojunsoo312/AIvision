## 5차시 물체 인식 (YOLO) + ① 박스 라벨

### 5-1 5차시 · 물체 알아보기

### 5-2 딥러닝 물체 인식
- 사진 + 정답 (라벨) 을 보여 주며 가르친다
- 정답 = 네모 (박스) + 놓인 자세 (세우기 · 눕히기 · 비스듬히)
- [그림] 브라켓 사진에 박스 세 개와 자세 이름

### 5-3 미리 공부한 모델에 몇 장 더 (미세조정)
- 처음부터: 사진 수백 장
- 기본 모델에서: **내 책상 사진 20장**
- [그림] 기본 모델 → + 20장 → 내 모델

### 5-4 반복 + 섞음 세트
- 내 사진은 **10번씩** → 충분히 배운다
- 원래 공부한 사진도 **섞는다** → 잊지 않는다
| 학습 방법 | 학습에 안 쓴 사진 점수 |
|---|---|
| 기본 모델 + 반복 + 섞음 | **0.995** |
| 기본 모델 + 반복, 섞음 없이 | 0.884 (잊음) |
| 처음부터 | 0.47 |
- 노트: 점수는 1 에 가까울수록 빠짐없이 정확히 찾는다.

### 5-5 사진 잘 찍는 법
- 세 자세를 비슷한 수로 · 흰 · 검 섞기
- 여러 자리 · 방향, 브라켓끼리 3 cm 이상
- 빈 책상도 한두 장
- [그림] 좋은 예 / 나쁜 예 (한 자리에만 몰림)

### 5-6 실습 · 사진 20장
```
python yolo/train/capture.py      # SPACE 저장 · q 끝
```

### 5-7 라벨이란
- 정답을 알려 주는 것 · 이번엔 **직접** 그린다
- [그림] 세 자세 사진 (세우기: 한 판이 위로 · 눕히기: 옆으로 누움 · 비스듬히: ㅅ 자)

### 5-8 실습 · 박스 라벨
```
python yolo/train/label.py
```
- `0` `1` `2` 자세 → 대각선 두 점 클릭 · `d` 취소 · `n` 다음
- 네모는 딱 맞게
- [화면] 라벨 화면

### 5-9 실습 · 학습 시작
```
python yolo/train/prepare.py
python yolo/train/train.py
```
- ⚠ 다른 창은 모두 끄고
- `학생 사진 n장 (×10) + 섞음 300장` · `device=0` 이면 GPU
- [화면] 학습 그래프 (손실이 내려가는 곡선)

### 5-10 정리 · 다음

### 6-3 두 가지 방식 한눈에

### 6-4 ① CAD 정합

### 6-5 ② 키포인트

### 6-9 실습 · k 로 두 방식 바꾸기

### 6-10 두 방식 비교
| | ① CAD 정합 | ② 키포인트 |
|---|---|---|
| 쓰는 것 | 컬러 + 깊이 | 컬러만 |

### 7-6 미션 · 블록 옮기기 (노트북 8-2)
- A, B 의 좌표를 적고 `"abs"` 로 옮기기
- 내려갈 때 `speed=10`, 멀리 갈 때 `path="joint"`

### 7-7 ★ 오류 읽는 법 (노트북 8-3)
- 빨간 글씨의 **마지막 줄**
- 한 번에 한 줄만 `#` 을 지우고 실행
| 실수 | 메시지 |
|---|---|
| mode 빠뜨림 | missing … 'mode' |
| 순서 바뀜 | 두 번째 인자는 'abs' 또는 'rel' … |
| 숫자 개수 | xyz는 mm 3개입니다 |
| 속도 범위 밖 | speed는 5–45 mm/s 입니다 |
- ⚠ 오류가 안 나도 맞는 건 아니다 (mm 대신 m → 베이스 쪽으로) → `where()` 로 확인
