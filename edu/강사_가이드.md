## 1. 교육 개요

- 1.1 교육 목표: 수업이 끝나면 학생이 할 수 있는 것
  - 펜던트와 코드로 팔을 움직이고, 좌표를 적어 물체를 집어 옮긴다
  - 카메라를 로봇에 맞추고 (손눈 캘리브), 맞았는지 스스로 검증한다
  - 물체 인식을 학습시키고, **6D 자세를 두 방식 (CAD 정합 · 키포인트) 으로 구해 비교**한다
  - 카메라가 찾은 물체를 집고, 흰 브라켓의 마커 불량을 가려낸다
- 1.2 대상과 전제: 로봇 처음, Python 수준 모름
- 1.3 시간표 (8차시 × 60분, 점심 별도) — 표 한 장. 오전 팔 + 손눈 캘리브, 오후 인식 · 자세 → 좌표 집기 → 보고 집기
- 1.4 장비 구성 (1인 1대, 8대 기준)
  - Jetson Orin Nano, SO-101 7축 팔 (팔로워) + 리더 팔, Orbbec 카메라
  - 모니터 · 키보드 · 마우스, 브라켓 (흰 · 검), 마커펜, 블록, ChArUco 보드, 자
- 1.5 오늘 쓰는 프로그램 한눈에 보기: 펜던트, 노트북 (Jupyter), 카메라 창, 3D 화면 (meshcat), 라벨 도구 두 개
- 1.6 전체 그림: 시스템 (`system.html`), 6D 두 방식 (`pose.html`), 픽앤플레이스 흐름 (`pickplace.html`)
- 1.7 이 가이드 읽는 법: 차시 구성, 표시 (★, 설명할 것, ⚠ 주의, ⏱ 시간 조절)

## 3. 차시별 진행

차시마다 같은 순서로 쓴다.

> 목표와 시간 배분 → 설명할 것 (요점, 말하는 방식은 강사에게) → 시연 순서 → 학생이 실행할 명령 → 잘 되면 보이는 화면 → 자주 막히는 곳과 해결법 → ⏱ 시간이 모자랄 때 · 남을 때

**오전: 팔 다루기 + 카메라 맞추기**

- 3.1 1차시 시작과 로봇팔 구조 (60)
  - 오리엔테이션 · 완성 데모 (보고 집기 · 불량 검사 영상)
  - **안전 수칙** · 비상 정지 · 장비 이름
  - **텔레오퍼레이션 체험** (`python deploy/teleoperate_7dof.py`): 리더 팔을 손으로 움직이면 팔로워가 따라온다. 관심 끌기가 목적이라 일찍, 길게. 미션: 블록 밀기 · 집어 보기
  - 방금 어떻게 움직였나: 관절 7개 · 서보 · 리더와 팔로워 (체험 뒤에 원리)
- 3.2 2차시 좌표와 자세 (60): 베이스 좌표 · TCP · xyz · rpy · 단위 mm · 도 / 펜던트로 축마다 움직이기 / meshcat 3D 화면
- 3.3 3차시 코드로 움직이기 (60): 노트북 1~7절 (`moveL` · `moveJ`, 절대 · 상대, `where()`, 관절, 홈) / 가상 팔 → 실기 (11절)
- 3.4 4차시 카메라와 손눈 캘리브 + 검증 (60)
  - 컬러 · 깊이 영상 (`vision_test.py`)
  - **왜 캘리브레이션을 하나**: 카메라는 픽셀 · 카메라 기준으로, 로봇은 베이스 기준 mm 로 말한다 → 둘 사이 번역표. 카메라를 옮기면 다시 해야 하는 이유, 1° 틀리면 약 8 mm 빗나감. ★시연: 카메라를 일부러 돌려 놓고 집기가 빗나가는 것 보여 주기 (카메라 창은 박스 가중치가 있어야 켜지므로 **강사 보드에서** 또는 미리 찍은 영상)
  - 렌즈 내부 값 (`get_intrinsic.py`) · **내부 파라미터 K 읽기** (fx · fy · cx · cy) / 손눈 개념: 카메라 좌표 → 로봇 좌표
  - 보드 사진 찍기 (`capture.py`) · 계산 (`compute.py`, 이어서 **팔 캘리브 L 자 자동 점검 · 보정**) · **외부 파라미터 T_base_cam 읽기** (오른쪽 열 = 위치, 왼쪽 3×3 = 방향)
  - **검증 3단계**: ① 계산 숫자 읽기 ② 책상 위 보드 높이 (`compare_pnp_depth.py`) ③ 팔 끝으로 코너 찍어 보기 (펜던트 / `moveL`). 통과 기준과 다시 찍는 법
  - 4차시 기록표 (학생마다 숫자 적기)

**점심**

**오후: 보고 집기**

- 3.5 5차시 물체 인식 (YOLO) + ① 박스 라벨 (60)
  - 딥러닝 인식 개념, 미리 학습한 모델에 몇 장 더 가르치기 (미세조정): 기본 모델에서 시작 · 내 사진 10번 반복 · 섞음 세트 (새것을 배우면서 원래 실력을 잊지 않게). 근거 숫자 (`docs/yolo.md`): 처음부터면 절반도 못 찾음, 섞음 없이 반복하면 원래 실력을 잊음
  - 사진 20장 찍기 (세 자세 · 흰 · 검 골고루) (`yolo/train/capture.py`)
  - ① 박스 + 자세 종류 라벨, **직접 그리기** (`label.py`) → 학습 시작 (`train.py`, 기본 모델 + 반복 + 섞음 세트)
  - 학습 동안: 키포인트 개념 미리
- 3.6 6차시 6D 자세 추정, 두 가지 방식 (60) — 그림 `pose.html`
  - ② 키포인트 라벨: **처음 2~3장 직접, `m` 으로 자동 찍기** 뒤 확인만 (`kpt_label.py`, 5차시 사진에 바로 · 라벨은 박스와 따로 `raw/kpt_labels` 에 저장) → 학습 (`kpt_train.py`, 끝나면 카메라 창이 학생 모델을 씀)
  - ① 결과 보기: 점군 · 책상 평면 빼기 · CAD 맞추기 (`roi_cloud.py`, `v` 3D 보기)
  - 두 방식 비교: 같은 브라켓을 `k` 로 번갈아, 숫자 비교. 강점 · 약점, 놓는 조건 (책상 위, 3 cm, 쌓으면 안 됨)
- 3.7 7차시 좌표 적어서 집고 놓기 (60): 접근 → 내려가기 → 잡기 → 올리기 (노트북 8절, 10단계 그림) / 미션: 블록 옮기기 / ★오류 읽는 법 (닿지 않는 좌표, mm · m, 절대 · 상대)
- 3.8 8차시 보고 집기와 응용 (60)
  - 잡는 자세 가르치기 (`teach_grasp`, 펜던트 `--grasp` 의 물건 칸): CAD 위에서 잡을 곳 · 접근 방향 정하기
  - 전체 연결: 카메라 창 → 「물체 위치 불러오기」 → 픽앤플레이스, 두 방식 어느 쪽으로든 (노트북 9절, `pendant/main.py --grasp`)
  - **불량 검사**: 흰 브라켓에 마커 → 카메라 창 `i` → 초록 양품 · 빨강 불량 · 보라 검사 안 함 (검은 브라켓) · 주황 브라켓 아님
  - 응용: 여러 개일 때 집는 순서 (불량 먼저 · 가까운 것부터), `load_all_pick_targets()` 로 브라켓 목록 (자세 · 판정 · 거리) 받아 `user_pickandplace.py` 에서 순서 정하기 · 정리 · 질문

## 5. 문제 해결 모음

- 5.1 팔: 포트가 안 열림, 움직이지 않음, 「IK 실패」 · 「go-to blocked」
- 5.2 카메라: 권한 (udev 규칙), 영상이 안 나옴, 「카메라 창이 응답하지 않습니다」 (30초), `device=cpu`, 노출 · 뎁스 필터 값
- 5.3 손눈 캘리브: 보드를 못 찾음, 검증 불통과 (숫자별 원인), 다시 찍는 법, 예비 캘리브로 바꾸기
- 5.4 학습 · 라벨: 학습 전에는 카메라 창이 안 켜짐, 결과가 나쁠 때, 예비 가중치, 키포인트 라벨 도구가 「박스 라벨이 있습니다」로 멈출 때 (`--labels`), 「기본 모델이 없습니다」 · 「섞음 세트가 없습니다」 경고 (보드 복사 파일 4개 확인), 「라벨한 사진이 n장」 (s 로 저장했는지)
- 5.5 자세 · 검사: 자세가 틀릴 때 (붙어 있음 · 쌓임 · 화면 가장자리), 키포인트 방식이 안 켜짐 (가중치), 검사가 틀릴 때 (그림자 · 케이블 · 검은 브라켓은 검사 안 함)
- 5.6 화면 · 환경: meshcat 흰 화면, 창이 안 뜸, `PYTHONPATH` 섞임, conda 환경 안 켜짐
- 5.7 카메라가 고장 났을 때: 예비 장면으로 `roi_cloud.py --replay` (화면 설명은 그대로)
