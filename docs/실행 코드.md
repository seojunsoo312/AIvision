# 실행 코드 (학생용)

수업 순서대로 정리했습니다. 노트북(코드로 팔 움직이기)은 「노트북 실습.md」에 따로 있습니다.

---

## 0. 터미널 열기

바탕화면 **「AIvision 터미널」** 아이콘을 더블클릭합니다. 터미널이 4칸으로 열리고, 모든 칸에 `(AIvision)` 이 켜져 있습니다.

| 칸 | 폴더 | 여기서 칠 명령 |
|---|---|---|
| 왼쪽 위 | `pendant` | `python main.py` (픽앤플레이스는 `--grasp`) |
| 오른쪽 위 | `vision` | `python handeye/…` |
| 왼쪽 아래 | `yolo` | `python train/…`, `python pose/roi_cloud.py` |
| 오른쪽 아래 | `AIvision` | 빈 칸 (그 밖의 명령) |

- 위 세 칸은 맨 윗줄에 그 칸에서 칠 명령이 보입니다.
- 아래 표의 명령은 **오른쪽 아래 칸**에서 그대로 칩니다. 다른 칸에서는 앞의 폴더 이름을 뺍니다.
  예: `python pendant/main.py` → 왼쪽 위 칸에서 `python main.py`
- 아이콘 없이 터미널을 열었다면 먼저:

```bash
conda activate AIvision
cd ~/AIvision
```

## 1. 로봇 팔 캘리브레이션

**오른쪽 아래 칸**(AIvision)에서 합니다. **펜던트는 꺼 둡니다** (펜던트가 팔을 잡고 있으면 캘리브가 팔에 연결하지 못합니다).

| 순서 | 명령 | 하는 일 |
|---|---|---|
| 1 | `bash deploy/make_serial_rules.sh` | 두 팔에 이름 붙이기 (처음 한 번만) |
| 2 | `bash deploy/calibrate_arms.sh` | 팔로워 → 리더 순서로 캘리브 |
| 3 | `python pendant/main.py` → **Connect** → **HOME** | 잘 됐는지 확인 |

**1번 (이름 붙이기)**: 화면에 나오는 대로 합니다.
1. 팔 USB 두 개를 모두 뽑고 Enter
2. **팔로워**(모터로 움직이는 팔)만 꽂고 Enter
3. **리더**(손으로 잡고 움직이는 팔)도 꽂고 Enter

중간에 비밀번호를 물으면 보드 로그인 비밀번호를 칩니다 (쳐도 화면에 안 보이는 게 정상). 마지막에 `/dev/so101_follower`, `/dev/so101_leader` 두 줄이 보이면 성공입니다.

**2번 (캘리브)**: 팔로워와 리더 각각, 아래 순서를 한 번씩 합니다.
1. 「저장된 캘리브가 있습니다」가 나오면 `c` 를 치고 Enter (예전 캘리브를 버리고 새로 함)
2. 팔을 **HOME 자세(L자, 모든 관절 0)** 로 두고 Enter. **이 자세가 관절 0° 가 되므로 정확히 맞춥니다.**
3. 관절을 **하나씩** 돌립니다. 턱이 있는 관절은 **턱에 닿을 때까지** 양쪽으로 천천히 돌립니다. 손목 돌리기(`wrist_roll`)와 그리퍼도 빼먹지 않습니다. `elbow_roll` 은 턱 없이 도는 관절이라 돌리지 않아도 됩니다.
4. 다 돌렸으면 Enter

- 표에는 관절 7개가 모두 나옵니다. `elbow_roll` 은 MIN 0 / MAX 4095 로 고정돼 `(고정)` 이라고 나옵니다. **다른 관절에 0 이나 4095 가 보이면** 잘못 기록된 것이니 그 팔만 다시 합니다.
- 안 돌린 관절이 있으면 「안 돌린 관절이 있습니다: …」가 나옵니다. 처음부터 다시 하고 그 관절도 돌립니다.
  팔로워만 다시: `bash deploy/calibrate_arms.sh follower` · 리더만 다시: `bash deploy/calibrate_arms.sh leader`
- 3번에서 HOME 을 눌렀을 때 팔이 갑자기 튀거나 이상한 자세로 가면, 바로 **Esc** 를 누르고 선생님을 부릅니다.

## 2. 카메라 확인과 캘리브레이션

| 순서 | 명령 | 하는 일 · 키 |
|---|---|---|
| 1 | `python vision/handeye/vision_test.py` | 카메라 화면이 나오는지 확인 |
| 2 | `python vision/handeye/get_intrinsic.py` | 카메라 내부 값 저장 (한 번만) |
| 3 | `python pendant/main.py` → **Connect** | 펜던트 켜기 (손눈 촬영 동안 계속 켜 둠) |
| 4 | `python vision/handeye/capture.py` (**새 터미널**) | 손눈 사진 찍기. `SPACE`=저장, `u`=마지막 삭제, `q`=종료 |
| 5 | `python vision/handeye/compute.py` | 카메라 위치 계산 |

- 4번은 펜던트로 팔 끝(보드)을 여러 자세로 옮겨 가며 찍습니다. 각 축으로 30° 이상 돌리고, 구석과 가운데를 섞어서 찍습니다.
- 카메라를 쓰는 명령은 **하나씩만** 켭니다. 이때 Orbbec Viewer가 켜져 있다면 반드시 끕니다.

## 3. YOLO 학습 (물체 알아보기)

| 순서 | 명령 | 하는 일 · 키 |
|---|---|---|
| 1 | `python yolo/train/capture.py` | 사진 찍기. `SPACE`=저장, `q`=종료 |
| 2 | `python yolo/train/label.py` | 라벨 달기. `0` 세우기 / `1` 눕히기 / `2` 비스듬히 → 대각선 두 점 클릭. `d` 또는 우클릭=취소, `n`=다음(물체 없는 사진) |
| 3 | `python yolo/train/prepare.py` | 학습용 / 검증용 나누기 |
| 4 | `python yolo/train/train.py` | 학습 (약 12분). **다른 창은 모두 끄고** 실행 |
| 5 | `python yolo/train/detect.py` | 학습 결과 확인 (실시간 박스) |

- 세 자세를 비슷한 수로, 여러 위치와 방향에서 찍습니다.

## 5. 펜던트로 픽앤플레이스

카메라 창은 다른 터미널에서 켜 둔 상태에서:

```bash
python pendant/main.py --grasp
```

1. 실제 팔이면 **Connect**
2. **「물체 위치 불러오기」**
3. **「픽앤플레이스」**

| 키 | 하는 일 |
|---|---|
| `Space` | 멈춤 (팔은 그 자리에서 버팀) |
| `Esc` | 비상 정지 (팔 힘이 빠짐, 손으로 받칠 수 있을 때만) |

- 놓을 위치는 펜던트의 「놓기 x / y」 칸에서 바꿉니다. 3D 화면 바닥에 빨간 원으로 보입니다.
- 「픽앤플레이스(유저생성)」 버튼은 내가 짠 `user_pickandplace.py` 의 `run(arm)` 을 실행합니다 (VS Code 로 고침).

## 6. 원격 조종 (리더 팔로 팔로워 움직이기)

**오른쪽 아래 칸**(AIvision)에서 합니다. **펜던트는 꺼 둡니다** (펜던트와 같은 팔을 동시에 쓸 수 없습니다).

```bash
python deploy/teleoperate_7dof.py \
  --robot.type=so101_follower \
  --robot.port=/dev/so101_follower \
  --robot.id=follower \
  --robot.dof_mode=7 \
  --teleop.type=so101_leader \
  --teleop.port=/dev/so101_leader \
  --teleop.id=leader \
  --teleop.dof_mode=7 \
  --display_data=true
```

1. 시작하기 전에 **리더를 팔로워와 비슷한 자세**로 둡니다. 자세가 많이 다르면 팔로워가 시작하자마자 리더 자세로 확 움직입니다.
2. 리더를 손으로 천천히 움직이면 팔로워가 따라 움직입니다.
3. 그래프 창이 같이 뜹니다. 관절마다 한 칸이고, **파란 선 = 리더**, **주황 선 = 팔로워** 입니다. 두 선이 벌어지면 팔로워가 못 따라가고 있는 것입니다.
4. 끝낼 때는 터미널에서 **`Ctrl + C`** 를 누릅니다.

- **`Ctrl + C` 를 누르면 팔로워 힘이 빠져 팔이 떨어집니다.** 팔을 낮은 자세로 두거나 손으로 받친 채 끕니다.
- 펜던트의 `Space` · `Esc` 는 여기서는 안 됩니다. 멈추려면 `Ctrl + C` 입니다.
- 리더를 빠르게 휘두르지 않습니다. 이 모드는 바닥이나 몸통에 부딪히는지 검사하지 않습니다.
- 그래프 없이 하려면 마지막 줄을 `--display_data=false` 로 바꿉니다.
