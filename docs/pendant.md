# pendant

로봇 팔을 손으로 움직이는 창입니다. 버튼을 누르면 팔이 따라가고, 브라우저에 같은 팔이 3D로 보입니다. 모터 계산, 3D 화면, 팔 설계도(URDF·메시)는 `motion/`에 있습니다.

그림으로 보기: 브라우저로 `docs/diagrams/index.html` 을 엽니다 (폴더 구조, 팔이 움직이는 길, 픽앤플레이스 흐름, 10단계).

## 실행

```bash
python pendant/main.py           # 조그 창
python pendant/main.py --grasp   # 조그 창 + 물건 위치 칸
python pendant/main.py --grasp --scale 0.6   # 창·글자 크기 직접 지정
```

창은 배율 0.9로 화면 왼쪽 위에 뜨고, Meshcat 3D 화면은 Chrome 창(주소창 없음)으로 그 오른쪽 빈자리에 맞춰 열립니다. 1080 높이 모니터에 맞춘 크기입니다. 아래가 잘리면 `--scale 0.8`처럼 줄입니다 (작을수록 작아짐). `--no-open`이면 브라우저를 열지 않고 주소만 터미널에 찍습니다.

## 화면 배치

```
┌ 상태 글자 (mode, TCP, rot, err) ─────┬ [Stop (Space)] [E-stop (Esc)] [Connect] ┐
│                                       │ [HOME]         [초기자세]    ☑TCP 경로  │
│                                       │                              ☑링크 색 구분│
├ Joints (J1~J6, S7, Gripper) ──────────┼ TCP (X, Y, Z, Rx, Ry, Rz) ──────────────┤
│ 현재값 넣기 · 관절 이동 · 관절 속도    │ 현재값 넣기 · TCP 이동 · 조그 속도       │
├ 사물의 위치 (x, y, z, Rx, Ry, Rz) ────┼ 적용 · 물체 초기화 · 대기/집기 위치로     │
│ 비활성화 (축 숨김 / 영역 숨김)         │ 픽앤플레이스 · 픽앤플레이스(유저생성)     │
│                                       │ 물체 랜덤 생성 · d/a · 놓기 x/y · 상태    │
└───────────────────────────────────────┴ 물체 위치 불러오기 ──────────────────────┘
```

| 조작 | 하는 일 |
|---|---|
| `Space` | **Stop**. 모든 이동을 멈춥니다. 모터 힘은 그대로라 팔은 그 자리에 섭니다. |
| `Esc` | **E-stop**. 팔 관절 6개의 힘(토크)을 끕니다. **실기에서는 팔이 처집니다.** 그리퍼는 힘을 유지해서 쥔 물체를 놓치지 않습니다. 손으로 받칠 수 있을 때만 씁니다. |
| TCP 경로 | Meshcat 에 TCP 가 지나간 선을 그립니다. |
| 링크 색 구분 | 켜면 링크마다 다른 색, 끄면 로봇 전체가 회색입니다. |
| d mm (대기) | 물체 표면에서 대기 위치까지 거리. |
| a mm (집기) | 대기 위치에서 집기 위치까지 들어가는 거리. |
| 놓기 x / y mm | 「픽앤플레이스」가 물체를 내려놓을 위치 (베이스 기준). Meshcat 바닥에 **보라색 구**로 보입니다. 누르는 순간의 값을 쓰고, 펜던트를 다시 켜면 기본값(`cad/model.yaml` 의 drop, 없으면 150, −100)으로 돌아갑니다. 「픽앤플레이스(유저생성)」은 학생 코드가 위치를 정하므로 이 칸을 쓰지 않습니다. |

## 물체를 쥐고 있을 때

픽앤플레이스가 그리퍼를 닫은 뒤(4단계)부터 놓을 때(8단계)까지는 상단에 **「물체 쥠」** 이 보입니다. 이동 중에 그리퍼가 공중에서 열리지 않게 이렇게 동작합니다.

| 상황 | 동작 |
|---|---|
| 쥔 채 실패 (팔이 못 닿음, 막힘) | 그 자리 **바로 아래로 천천히** 집었던 높이까지 내려가 그리퍼를 열고, 30mm 든 뒤 멈춥니다. 상태 줄: `… → 물체를 내려놓고 멈춤` |
| 내려가는 것도 막힘, 또는 통신 오류 · Stop | 더 움직이지 않고 **쥔 채로 멈춥니다**. 상태 줄: `물체를 쥔 채 멈춤 — 손으로 받친 뒤 내려 주세요` |
| HOME · 초기자세 | 팔만 움직이고 그리퍼는 지금 값을 유지합니다 |
| 창 닫기 · Disconnect | 「물체를 쥐고 있습니다」 확인 창이 뜹니다 (계속하면 힘이 꺼져 떨어질 수 있음) |
| 픽앤플레이스 다시 누르기 | 시작하지 않습니다 (첫 단계가 그리퍼 열기라서) |

쥔 채 멈췄을 때는 **손으로 물체를 받치고 Gripper Open** 을 누르면 놓습니다. 그때 「물체 쥠」 표시도 풀립니다. 학생 코드의 `arm.grip(값)`도 10 미만이면 쥔 것으로, 그 이상이면 놓은 것으로 봅니다.

실행 기록은 `~/aivision_logs/날짜.log`에 남습니다 (`docs/jetson_setup.md` 10번).

Meshcat 오른쪽 위 Scene 패널에서 Background(배경색)는 꺼 둔 상태라 바탕이 흰색입니다. 다시 체크하면 원래 배경이 나옵니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `main.py` | 프로그램을 켭니다. 조그 창과 3D를 같이 띄웁니다. |
| `gui_app.py` | 조그 창. 방향 버튼, 관절, 좌표, 실기 연결(Connect). |
| `teach_grasp.py` | 물건 위치 칸. 어디 두고 어떻게 집을지 정하고, 픽 버튼을 누릅니다. 계산은 `motion/grasp.py`에 맡깁니다. |
| `ui_style.py` | 창 글꼴과 배율 (`--scale`). conda에서 한글이 깨지지 않게 Noto를 쓰고, 소수 배율에서 버튼 모서리가 어긋나지 않게 그리는 방식을 정합니다. |

## 같이 쓰는 곳

- 3D 화면은 `motion/visualizer.py`, 팔 설계도와 부품 STL은 `motion/robot/`입니다.
- 실기 Connect는 이 PC에서 `lerobot-calibrate`로 만든 팔로워 캘리브를 읽습니다. 그 JSON은 이 폴더에 없습니다.
- 물건 인식은 `yolo/pose/roi_cloud.py`입니다. 물건 위치 칸은 그 결과를 받아 옵니다.
- 패키지 목록은 `docs/requirements.txt`, 설계 메모는 `docs/pendant_spec.md`입니다.
