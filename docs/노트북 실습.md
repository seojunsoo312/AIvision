# 노트북 실습 (코드로 팔 움직이기)

## 노트북 열기

```bash
conda activate AIvision
cd ~/AIvision
jupyter notebook "로봇 제어 실습_학생.ipynb"
```

- VS Code 로 열어도 됩니다. 커널은 **AIvision** 을 고릅니다.
- **펜던트는 끄고** 합니다. 노트북이 3D 화면(Meshcat)을 따로 띄웁니다.
- 칸은 위에서 아래로 한 번씩 실행합니다. 「팔 켜기」 칸을 두 번 실행하면 팔이 겹칩니다.

## 좌표 약속

- 로봇 기준: **+X 앞, +Y 왼쪽, +Z 위**
- 위치는 mm, 자세(rpy)는 도
- `"rel"` = 지금 위치에 더하기, `"abs"` = 로봇 기준 목표 위치
- `rpy` 는 더하는 각도가 아니라 **목표 자세**
- 이동 명령은 도착할 때까지 그 칸에서 기다립니다

## 명령

| 명령 | 하는 일 |
|---|---|
| `from motion import Arm, load_pick_targets` | 명령 불러오기 (맨 처음 한 번) |
| `arm = Arm()` | 가상 팔 켜기 |
| `arm = Arm(mode="real")` | 실제 팔 켜기 (**선생님이 실기라고 한 뒤에만**) |
| `arm.where()` | 지금 관절 · 그리퍼 · 손끝 위치(`xyz_mm`) · 자세(`rpy_deg`) |
| `arm.initial()` | 작업 시작 자세 (그리퍼 닫힘) |
| `arm.home()` | 홈 자세 (관절 모두 0, L자) |
| `arm.moveL([x, y, z], "abs")` | 손끝을 좌표로 직선 이동 |
| `arm.moveL([dx, dy, dz], "rel")` | 지금 위치에서 더한 만큼 이동 |
| `arm.moveL([x, y, z], "abs", rpy=[r, p, y])` | 위치와 손목 자세를 함께 |
| `arm.moveL(..., speed=10)` | 속도 지정 (mm/s, 기본 25, 5~45) |
| `arm.moveL(..., path="joint")` | 직선 대신 관절 이동으로 (멀리 옮길 때) |
| `arm.moveJ([j1, j2, j3, j4, j5, j6], "abs")` | 관절 6개를 각도(도)로 |
| `arm.moveJ([...], "rel", gripper=20)` | 관절과 그리퍼를 함께 |
| `arm.grip(0 ~ 100)` | 그리퍼만 (0=닫힘, 100=완전히 열림) |
| `pick = load_pick_targets(arm)` | 카메라로 물체 위치 받기 (**카메라 창을 먼저 켜 둠**) |
| `arm.stop()` | 진행 중인 이동 멈춤 |
| `arm.close()` | 팔 끄기 (다시 쓰려면 커널 재시작 후 처음부터) |

## `load_pick_targets` 결과

| 값 | 뜻 |
|---|---|
| `pick.p_xyz`, `pick.p_rpy` | 대기 위치 (물체 위) |
| `pick.g_xyz`, `pick.g_rpy` | 집기 위치 |
| `pick.place_rpy` | 내려놓을 때 손목 자세 |

## 예시: 카메라로 집어서 옮기기

```python
drop_x, drop_y = 150.0, -100.0          # 놓을 위치
pick = load_pick_targets(arm)
z_g = pick.g_xyz[2]                     # 집은 높이

arm.initial()
arm.moveL(pick.p_xyz, "abs", rpy=pick.p_rpy)        # 물체 위로
arm.grip(30)                                        # 조금 열기
arm.moveL(pick.g_xyz, "abs", rpy=pick.g_rpy)        # 내려가기
arm.grip(0)                                         # 잡기
arm.moveL([0, 0, 30], "rel")                        # 들어 올리기
arm.moveL([drop_x, drop_y, z_g + 50], "abs", rpy=pick.place_rpy, path="joint")
arm.moveL([drop_x, drop_y, z_g], "abs", rpy=pick.place_rpy)
arm.grip(30)                                        # 놓기
arm.moveL([0, 0, 50], "rel")
arm.initial()
```

## 오류가 나면

- 팔이 닿지 않는 좌표면 `ArmError: 목표까지 … mm 남음 (도달 못함)` 또는 `IK 실패` 가 납니다. 좌표를 작업대 쪽으로 줄여 봅니다.
- 숫자 개수가 틀리면(xyz 는 3개, moveJ 는 6개) 오류 문구가 무엇이 틀렸는지 알려 줍니다.
- 팔을 바로 멈추려면 노트북의 **■(중단) 버튼**을 누릅니다. 팔이 그 자리에서 멈추고 `ArmError: 중단 — ■ 버튼…` 이 뜹니다. 다음 칸은 그대로 이어서 실행할 수 있습니다.
